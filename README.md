# Speedster

Booster-powered flying-car racer for phone and PC. Drive, fly and jump across a 3x3 grid of lanes, dodge traffic, collect coins and unlock new cars.

**Play in your browser:** https://jomzrules-dotcom.github.io/speedster/

## Controls
- **Phone:** swipe up / down / left / right (one swipe = one lane). Up from the sky lane = jump, up again = double jump.
- **PC:** arrow keys or WASD. Esc / P = pause.

## Modes
- **Free Ride:** endless run, speed keeps rising. One crash ends the run.
- **Time Trial:** 10 levels across 5 maps (Neon City, Desert Run, Coast Bridge, Snow Peaks, Mars Colony). Checkpoints add time.

Coins buy and upgrade cars in the Garage (sedan, sports coupe, wedge supercar, F1 car).

Tip: on a phone, use "Add to Home Screen" to play full screen and offline.
